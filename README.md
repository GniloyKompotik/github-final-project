## Overview
This repository contains a Bash script designed to calculate **Simple Interest** based on user-provided inputs. The project is created as part of the final hands-on assignment for the **IBM Full Stack Software Developer Professional Certificate** program on Coursera.

Simple interest is a quick and easy method of calculating the interest charge on a loan or investment. The formula used by this tool is:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **$P$ (Principal):** The initial sum of money invested or borrowed.
* **$R$ (Rate of Interest):** The annual interest rate (in percent).
* **$T$ (Time):** The time duration for which the money is borrowed/invested (in years).
